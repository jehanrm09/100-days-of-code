

The Problem: Print numbers from 1 to 50. But:
If a number is divisible by 3, print "Fizz" instead of the number.
If a number is divisible by 5, print "Buzz" instead of the number.
If a number is divisible by both 3 and 5, print "FizzBuzz".

The Level-Up Twist: You must write this using the most efficient if/elif structure.
If you put the conditions in the wrong order, the program will fail the "FizzBuzz" check!
